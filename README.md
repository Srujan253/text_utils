# 📝 text_utils

A **JavaScript-based web app** for performing various **text manipulation and utility functions**.  
Designed to be fast, lightweight, and responsive — ideal for daily productivity and text editing tasks.

---

## 🚀 Features

- 🔠 Convert text to uppercase, lowercase, title case, etc.
- ✂️ Trim extra spaces and line breaks
- 🔍 Character and word count
- 💡 User-friendly interface
- 📱 Fully responsive design with modern CSS
- ⚡ Runs easily in any modern browser

---

## 🛠️ Technologies Used

- **JavaScript** – Main logic for text processing
- **CSS** – For styling and responsiveness
- **HTML** – Structure of the web app

---

## 🧑‍💻 Getting Started

### ✅ Prerequisites

- Any modern web browser (Chrome, Firefox, Edge, etc.)
- *(Optional)* Live Server extension in VS Code or any HTTP server (for local development)

---

### 📂 How to Run the App

#### 🔹 Option 1: Open Directly
1. Clone the repo:
   ```bash
   git clone https://github.com/Srujan253/text_utils.git
   cd text_utils
   npm install
   npm start

🧪 How to Use
Type or paste your text into the input area.

Choose an action (e.g., uppercase, lowercase, trim, count).

View the result instantly below the input box.
